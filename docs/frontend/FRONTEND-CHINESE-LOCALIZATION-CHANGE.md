# PetLink 前端中文化变更记录

日期：2026-09-02  
范围：电脑工作台、UniApp 移动端、页面标题、角色/状态/物种/性别展示

## 结论

前端固定用户可见文案已统一为中文。角色、业务状态、物种、性别和统计字段使用集中映射显示；所有提交给后端的 Frozen 枚举值、字段名、路由和数据库值保持不变。

## 主要变更

- 品牌、导航、标题、说明、按钮、筛选项、对话框、空状态、校验错误和图片上传提示中文化。
- Element Plus 使用简体中文语言包；HTML、H5 和 UniApp 应用标题统一为“宠链”。
- 电脑端和移动端分别新增 `src/utils/displayText.js`，集中转换角色、线索、任务、动物、领养、公告等枚举。
- 图片上传界面不再直接展示 `token` 英文标签，改为“图片标识”。
- 开发用救助人员种子昵称改为中文；历史业务数据仍按原值展示，不在前端擅自翻译或改写。

## 兼容边界

- `ADMIN`、`RESCUER`、`USER`、状态码等仅保留在程序条件、请求体和 Frozen 接口契约中，不直接显示。
- `JPG`、`JPEG`、`PNG`、`MB` 属于文件格式和容量单位，按行业通用写法保留。
- 用户输入、公告正文、数据库历史测试数据和文件名属于业务数据，不计入固定前端文案。

## 验证证据

- 后端：269/269，通过；数据库结构及第二至第八模块静态门禁全部通过。
- 电脑端：20/20 测试通过，生产构建通过；已补个人资料页和负责动物领养概览入口，并补充登录失败页面提示回归。
- 移动端：18/18 测试通过，H5 生产构建通过；已修正领养概览响应字段映射并收口初始加载网络异常。
- 前端静态核验：29 个移动页面、7 个移动功能域、10 个电脑端业务页和 72 个 Frozen REST API 全部通过。
- 本机浏览器：电脑端登录态 9 个业务页面、移动端 5 个访客页面逐页扫描，无固定用户可见英文。
- 控制台：电脑端无错误/警告；移动端无错误，仅有 UniApp 依赖内部的 Vue Router 弃用警告。
- 非 JSON、超时和无法连接服务器的请求不再直接展示 Axios/浏览器英文错误。

## 回归测试

两端均新增 `tests/localization.test.mjs`，锁定角色、状态、物种和性别的中文映射，防止后续改动重新暴露英文枚举。

## 缺失图片 404 修复

动物档案中的历史图片记录可能指向已清理的本地文件。受保护图片请求现使用静默错误模式：接口返回 404 时自动显示占位图，不再由 Axios 全局拦截器弹出英文错误；普通业务接口错误提示不受影响。电脑端新增 `tests/auth-image-fallback.test.mjs` 锁定该行为。
