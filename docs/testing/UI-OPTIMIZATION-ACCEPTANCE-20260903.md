# PetLink V1.0 UI 全面优化验收记录

执行日期：2026-09-03  
范围：PC 管理/救助工作台、Mobile H5 用户/救助端  
原则：只调整视觉、布局和交互反馈，不改变 Frozen API、业务状态机、权限规则或请求值。

## 1. 本轮完成内容

### 视觉系统

- PC 建立统一的纸张米白、森林绿、珊瑚橙、芥末黄和鼠尾草色令牌。
- 统一圆角、阴影、边框、标题层级、表格行高、抽屉/弹窗留白和按钮反馈。
- 增加键盘 `:focus-visible` 焦点样式，提升键盘可操作性与可见性。
- 状态徽章统一为“中文状态 + 圆点语义色”，保持状态码仅在程序和接口层使用。
- 二次设计升级加入克制的玻璃感表面、低饱和多层阴影、细网格背景、渐变主按钮、指标卡呼吸点和统一的高级留白；在不增加业务噪音的前提下强化层次和品牌识别。

### PC 端

- 侧边导航增加更清晰的选中态、悬停反馈、角色信息层级和退出按钮触控尺寸。
- 页面标题区增加视觉基线，工具栏、筛选器、表格、分页和业务卡片统一密度。
- 总览工作台加入救助中心主视觉、指标卡装饰层和更明确的工作台层级。
- 上传器、图片网格、回访详情、空状态和错误提示同步升级，避免页面之间出现旧版圆角、边框和阴影。
- 登录页改为品牌化双栏布局，小屏自动切换为单列，并接入主视觉。

### Mobile 端

- 统一卡片、按钮、输入框、筛选器、提示框、时间线和底部导航的间距与圆角。
- 所有主要操作按钮保持适合触控的最小高度，输入框补充焦点反馈。
- 首页救助主视觉加入图文分层、渐变遮罩和安全裁切，副标题保持可读。
- 状态徽章和返回按钮补充语义标签与更大的触控区域。
- 头部和底部导航采用半透明层、细边界和主动状态光晕；上传图片、筛选、空状态和加载状态使用同一套触控表面。

### 图标系统升级

- PC 与 Mobile 分别接入统一的语义 SVG 图标路径字典，覆盖导航、返回、发送、查看、刷新、收藏、添加、删除、关闭、确认、退出和品牌标识等高频操作。
- PC 使用 `petlink-pc/src/components/NavIcon.vue`，Mobile 使用 `petlink-mobile/src/components/Icon.vue`；两端图标尺寸、描边风格、颜色继承和悬停/按下反馈保持一致。
- 清理导航和业务操作中的 Unicode 字符图标，避免字体差异、基线错位和读屏语义缺失；交互图标补充 `aria-label`/隐藏语义，纯装饰图标保持 `aria-hidden`。
- 图标升级仅涉及视觉组件与交互反馈，不改变 API、请求值、状态机、权限或数据结构。
