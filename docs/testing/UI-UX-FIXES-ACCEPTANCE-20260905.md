## 安全与数据边界

- 删除用户与公告均为逻辑删除，不破坏历史外键和审计链。
- 删除用户后旧 JWT 立即失效，已用账号不可重新注册冒用历史身份。
- 公告删除使用乐观锁，过期版本返回冲突，不覆盖其他管理员的更新。
- 所有列表筛选在数据库分页前执行，不使用仅筛当前页的假搜索。
