# PetLink 前端依赖安全审计

日期：2026-09-02

## 结论

- 电脑端生产依赖：`npm audit --omit=dev` 为 0 项。已将 Axios 从 1.7.9 升级到 1.20.0、Element Plus 从 2.9.1 升级到 2.14.5，并通过 12/12 测试、生产构建和页面回归。
- 电脑端完整依赖树：仍有 2 项来自 Vite 5 构建工具链的中/高风险报告，只作用于本地开发服务器；演示时仅绑定本机，不对公网开放。
- 移动端完整依赖树：37 项；按 `--omit=dev` 统计为 25 项，主要由当前整套 UniApp CLI、国际化、压缩和图片构建依赖传递引入。

## 处置边界

`npm audit` 对移动端给出的自动修复需要跨主版本，且会把当前协调版本的 `@dcloudio/*` 套件替换为不兼容版本。Frozen 交付版不执行 `npm audit fix --force`，避免破坏 29 个页面、H5/小程序构建链和现有契约。

后续应建立独立升级分支，将全部 `@dcloudio/*` 包按同一发行线整体升级，并重新执行：29 页面路由检查、11/11 移动端测试、H5 与微信小程序构建、图片上传、登录返回栈和真机兼容测试。在升级完成前，开发服务器仅允许本机访问，不部署到不受信任网络。

## 验证命令

```bash
cd petlink-pc
npm audit --omit=dev

cd ../petlink-mobile
npm audit --omit=dev
```
