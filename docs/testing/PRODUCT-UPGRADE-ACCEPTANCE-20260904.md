## 3. 证据与复现

- `scripts/verify-all.sh`：后端、静态门禁、前端测试构建、契约与历史冻结包哈希。
- `scripts/cross-platform-e2e.mjs`：支持 PETLINK_E2E_ADMIN_ACCOUNT / PETLINK_E2E_RESCUER_ACCOUNT / PETLINK_E2E_OPERATOR_PASSWORD，测试账号由调用方提供。
- `scripts/account-lifecycle-e2e.mjs`：真实库新增隔离账号、测试权限与并发，会创建带验收名称的线索与任务，只应在测试库运行。
- 本轮日志：`docs/testing/evidence/product-upgrade-20260904/`。
- UI 操作由内置浏览器完成，不使用静态源码断言冒充实际点击；本地测试账户不复制到线上。

## 5. 明确未完成的验收与运营边界

- 独立 Chrome / Edge、HBuilderX、Android / iOS 真机、相机相册授权及弱网验收未完成。内置 Chromium 不能替代这些平台的签字。
- 本轮浏览器访问线上页面时控制工具超时；正式构建的实际 UI 在本地同源预览通过，线上通过网络/API/容器检查，不能冒称线上全部页面已逐个点击验收。
- 手机窄屏预览完成视觉检查，但工具实际视口与请求尺寸不完全一致，不记录为精确 390px 或真机通过。
- 保留原有未指定年份/状态的演示数据；本地旧测试内容仍有英文名称/健康描述，它们属于数据内容，不是新界面调试文案，不批量篡改用户历史记录。
- HTTPS、独立强密码、依赖漏洞升级、完整备份恢复演练仍是正式运营前加固项；当前公网演示仍为 HTTP，不等于企业级生产安全认证。
