# PetLink V1.0 异常与安全测试报告

执行日期：2026-09-02  
范围：M01～M08 的鉴权、授权、状态冲突、并发、文件事务与审计

## 1. 结论

计划内异常路径和安全规则已由后端自动化测试、静态检查及真实 MySQL 冒烟共同覆盖，最终纳入 269/269 全量回归并通过。未发现阻断 V1.0 冻结的鉴权、越权、并发一致性或事务残留问题。

## 3. 重点数据库审计证据

公告链已验证：

```text
CREATE    NULL       -> DRAFT
PUBLISH   DRAFT      -> PUBLISHED
WITHDRAW  PUBLISHED  -> WITHDRAWN
```

用户管理链已验证：

```text
SYS_USER DISABLE           ENABLED  -> DISABLED
SYS_USER ENABLE            DISABLED -> ENABLED
SYS_USER PROMOTE_RESCUER   NULL     -> NULL
```

## 4. 测试结果解释

全量测试日志中可见文件清理服务输出模拟异常日志，这是异常恢复测试主动注入的数据库/文件故障；对应测试断言“单行失败不终止剩余批次”和“危险残留保留人工检查”，测试本身通过，不是验收失败。

## 5. 已知非阻断项

- 正式文件孤儿扫描和 BOUND 临时文件重试清理已实现，包含 24 小时安全窗口、路径/符号链接防护、单条失败隔离和基础设施测试；部署后仍需观察定时任务日志与实际文件目录。
- 生产部署前必须通过环境变量替换开发 JWT secret、数据库凭据并收紧 CORS 域名，同时确认定时任务和文件目录具备最小权限。

## 6. 判定

V1.0 计划内异常与安全验收：**通过**。生产环境配置加固仍是部署动作，不应使用仓库中的开发默认值直接上线。
