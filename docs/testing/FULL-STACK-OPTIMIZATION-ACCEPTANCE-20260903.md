# PetLink V1.0 全栈优化验收记录

执行日期：2026-09-03  
范围：Spring Boot 后端、PC 管理/救助工作台、UniApp Mobile H5、MySQL 真实闭环  
目标：在不改变 Frozen API、数据库结构、状态机和权限契约的前提下，提升可观测性、并发一致性、异常体验、响应式布局和交付可靠性。

## 1. 优化内容

### 后端可靠性与可观测性

- 新增 `RequestCorrelationFilter`：规范化/生成 `X-Request-Id`，写入响应头和日志 MDC；拒绝过长或不安全的请求编号，避免日志注入。
- CORS 暴露 `X-Request-Id`，并补充 `X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy` 安全响应头。
- `verify-all.sh` 自动发现项目缓存 JDK 17、macOS `java_home` 和常见 Corretto/JDK 安装路径，降低本地启动门槛。
- 保持原有 JWT、权限、状态机、事务和数据库约束不变。

### PC 前端

- 列表分页增加请求序列保护，快速筛选、翻页或刷新时，旧响应不能覆盖最新结果。
- Axios 请求自动携带请求追踪编号，错误对象保留该编号，便于定位问题。
- 加入离线状态提示、页面标题、跳过导航链接、键盘焦点样式和响应式表格横向滚动。
- 图片使用懒加载/异步解码；固定操作列使用不透明背景，避免窄视口下内容穿透。
- 刷新按钮、表格 `row-key`、关键字段最小宽度和溢出提示统一收口。
- 二次视觉升级覆盖工作台、登录页、导航、指标卡、上传器、图片网格、回访详情和空状态，统一玻璃感表面、渐变按钮、细网格背景和多层阴影。

### Mobile 前端

- 分页列表增加请求序列保护，筛选刷新后的最新结果优先。
- 普通请求和上传请求自动携带请求追踪编号，并保留错误编号。
- 接入离线提示、图片懒加载、触控反馈和减弱动态效果支持。
- 救助任务页显示时安全刷新“待接取”和“我的任务”两个队列。
- 统一头部/底部导航主动态、触控反馈、表单聚焦态和图片上传状态。

## 3. 真实跨平台闭环

命令：

```bash
PETLINK_E2E_OPERATOR_PASSWORD='（通过环境变量注入）' node scripts/cross-platform-e2e.mjs
```

结果：`CROSS_PLATFORM_E2E_PASSED checks=40`，40/40 通过。

覆盖链路：

- Mobile USER 注册、发布线索；PC ADMIN 审核；PC/Mobile RESCUER 同时看到待接取任务。
- Mobile 接取；PC 待接取列表同步移除；PC 开始；Mobile 追加记录；PC 提交救助成功。
- 动物档案、观察期、开放领养、收藏、领养申请、管理员批准、领养回访和公告发布/读取。
- 管理员禁用/恢复用户后，旧令牌立即失效/恢复；USER 越权访问管理和救助接口均被拒绝。
- 统计接口覆盖全业务状态，关联线索→任务→动物→领养→回访链路无断链和重复记录。
